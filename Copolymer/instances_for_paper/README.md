# Instances for the Paper

This folder contains the datasets, instances, scripts, and results used in this study.

- `datasets.zip`

  Contains the original datasets collected from the literature, the processed datasets used in this study, and all scripts used for preprocessing.

- `learning.zip`

  Contains the scripts and results for Phase 1, as described in Section 3.1.

- `MILP.zip`

  Contains the instance files, scripts, and results for Phase 2, as described in Sections 3.2 and 3.3.
