# mol-infer/Copolymer
This folder contains the codes and instances used for the paper:

<p>Jianshen Zhu, Raveena Rai, Taiyo Sohkawa, Naveed Ahmed Azam, Kazuya Haraguchi, Liang Zhao and Tatsuya Akutsu:<br>
  Mixing Vector Model for Copolymer Inference via Mixed Integer Linear Programming.<br>
</p>

-----
The folder structure is organized as follows:
1. Module 1
   - Generate Descriptors
   - Generate Quadratic Descriptors
   - Preprocessors
1. Module 2
   - Constructing Prediction Functions
1. Module 3
   - Solving an MILP for the Inverse Problem
1. Instances for the paper
   - Original data sets used in the paper
   - Instance files used for Tables 4, 5 and 6
  
Please refer each folder for detailed descriptions.
