# mol-infer/Copolymer

This folder contains the code and instances used for the following paper:

<p>
Jianshen Zhu, Raveena Rai, Taiyo Sohkawa, Naveed Ahmed Azam, Kazuya Haraguchi, Liang Zhao, and Tatsuya Akutsu:<br>
Mixing Vector Model for Copolymer Inference via Mixed Integer Linear Programming.
</p>

---

The folder structure is organized as follows:

1. **Module 1**
   - Generate Descriptors
   - Generate Quadratic Descriptors
   - Preprocessors

2. **Module 2**
   - Constructing Prediction Functions

3. **Module 3**
   - Solving an MILP for the Inverse Problem

4. **Instances for the Paper**
   - Original datasets used in the paper
   - Instance files used for Tables 4, 5, and 6

Please refer to each folder for detailed descriptions.
